作为目前 Windows、macOS 和 Linux 平台上兼具开源、高颜值与活跃维护特性的代理客户端，**Clash Verge Rev**（基于 Meta / Mihomo 内核开发）已成为广大科学上网与外贸科研用户替代已停更原版 Clash 的首选工具。

很多新手朋友在购买高品质 IPLC 专线机场后，常常遭遇“网页打不开”、“外服游戏无法联机”或“命令行终端走不了代理”的问题。本篇教程将带你从零掌握 Clash Verge Rev 的核心配置要领。

---

## 一、客户端准备与基础安装

在开始前，请确保从官方 GitHub Release 仓库下载最新版本，避免下载经过二次打包的仿冒恶意安装包：

1. **Windows 用户**：推荐下载 `Clash.Verge_x.x.x_x64-setup.exe` 安装版；
2. **macOS 用户**：苹果芯片（M1/M2/M3/M4）选择 `aarch64.dmg`，英特尔芯片选择 `x64.dmg`；
3. **初次安装权限**：安装完成后，首次启动若弹出系统防火墙拦截提示，请务必全部勾选**专用网络与公用网络**权限。

---

## 二、一键导入机场订阅配置

1. 打开你所订阅的机场控制面板（如云界线、大佬云等后台）；
2. 找到 **“一键导入”** 或 **“复制 Clash 订阅链接”** 选项；
3. 进入 Clash Verge Rev 界面，点击左侧菜单栏的 **“订阅 (Profiles)”**；
4. 将复制的订阅链接粘贴至上方输入框中，并点击右侧的 **“导入 (Import)”** 按钮；
5. 导入成功后，鼠标右键点击该订阅卡片，勾选 **“选择 (Select)”** 将其激活生效。

```yaml
# 订阅配置结构示例 (Clash Meta 标准片段)
mixed-port: 7897
allow-lan: false
mode: rule
log-level: info
ipv6: false
external-controller: 127.0.0.1:9097
dns:
  enable: true
  listen: 0.0.0.0:1053
  enhanced-mode: fake-ip
  nameserver:
    - 223.5.5.5
    - 119.29.29.29
```

## 三、开启系统代理与选择高速节点

1. 点击左侧 **“代理 (Proxies)”** 菜单栏；
2. 推荐选择 **“规则 (Rule)”** 模式（实现国内直连、海外走专线的智能分流，避免浪费专线流量）；
3. 在节点选择组中，优先选择延迟低且丢包率为 0% 的亚太专线节点（如香港 IPLC 或日本 IEPL）；
4. 打开左侧 **“设置 (Settings)”**，将 **“系统代理 (System Proxy)”** 开关切换为开启状态；
5. 此时打开浏览器访问 `Google` 或 `YouTube`，即可验证节点是否连通。

## 四、高阶必备：开启 TUN 虚拟网卡模式

普通代理仅能接管支持 HTTP/HTTPS 代理协议的浏览器软件，对于以下场景往往无法生效：
- **Steam / Epic / Apex Legends 外服游戏联机**；
- **CMD / PowerShell / Git 终端命令行工具**；
- **Spotify 等部分严格检验网卡层流量的桌面应用程序**。

### 开启步骤：
1. 点击左侧 **“设置 (Settings)”**；
2. 找到 **“内核管理”**，确保内核选择为 **Clash.Meta (Mihomo)**；
3. 找到 **“服务模式 (Service Mode)”** 并点击安装（Windows 会弹出 UAC 提权确认）；
4. 安装成功后，找到 **“TUN 模式 (Tun Mode)”** 开关并启用；
5. 此时系统会自动创建一张虚拟网卡，全局无缝接管整机的所有 TCP 与 UDP 流量，无需再单独配置环境变量。

## 五、常见疑难问题排查 (FAQ)

### Q1: 订阅导入失败或提示 Network Error？
> **解答**：这通常是因为本地直连无法直接访问机场订阅下发服务器。可先在浏览器中开启系统临时代理，或者检查订阅链接是否含有非法字符。

### Q2: 开启代理后国内网站（如淘宝、网易云）加载变慢？
> **解答**：请务必确保分流模式为 **“规则 (Rule)”** 而非“全局 (Global)”。如果依然卡顿，可进入设置更新最新的 GeoIP 与 GeoSite 分流规则数据库。
