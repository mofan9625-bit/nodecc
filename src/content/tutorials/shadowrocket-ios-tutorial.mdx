作为 iOS 平台上最经典、操作门槛最低的代理工具，**Shadowrocket（俗称小火箭）** 凭借着对 Shadowsocks、Vmess、Vless、Trojan、Hysteria2 等协议的全面兼容，以及极佳的后台省电机制，成为了绝大多数 iPhone 与 iPad 用户的装机必备神器。

本文将为你详解从零安装、订阅导入到日常网络分流的最佳实践。

---

## 一、海外 Apple ID 获取与小火箭正版下载

由于众所周知的原因，Shadowrocket 在中国大陆 App Store 处于下架状态。下载小火箭必须使用**非国区 Apple ID**（如美区、日区、港区）：

1. **准备海外 Apple ID**：你可以自行注册一个免费美区 Apple ID，或者在合规数码平台购买已购买过小火箭的独享成品号；
2. **退出 App Store 账号**：打开 App Store，点击右上角头像，滑到最底部点击“退出登录”（**切记：请仅在 App Store 登录，绝对不要在系统“设置”中登录 iCloud，以保护个人手机隐私安全**）；
3. **搜索下载**：登录海外账号后，搜索 `Shadowrocket`，认准开发者为 **Pan modal** 的原版应用（图标为浅蓝底白色小火箭），售价为 $2.99。

## 二、机场订阅链接导入方法

成功安装后，将优质机场订阅导入小火箭主要有以下两种方式：

### 方法 1：一键导入（最推荐）

1. 用 Safari 浏览器登录你的机场后台面板（例如 <a href="/go.html?id=yunjiexian" target="_blank" rel="nofollow sponsored noopener noreferrer" class="text-sky-600 dark:text-sky-400 hover:underline font-semibold">云界线</a> 或 <a href="/go.html?id=dalaoyun" target="_blank" rel="nofollow sponsored noopener noreferrer" class="text-sky-600 dark:text-sky-400 hover:underline font-semibold">大佬云</a>）；
2. 找到“便捷导入 / 订阅管理”区域，点击 **“一键导入到 Shadowrocket / 小火箭”**；
3. 系统将弹出提示：“在 Shadowrocket 中打开？”，点击“打开”，客户端便会自动完成所有高速节点与分流规则的拉取。

### 方法 2：扫码导入 / 剪贴板导入

若你在电脑端使用，可直接打开机场面板生成的订阅二维码：
- 打开手机 Shadowrocket，点击左上角**扫描框图标**，对准屏幕二维码扫描；
- 或者复制机场提供的通用订阅链接（HTTPS 开头），打开 Shadowrocket 点击右上角 `+` 号，类型选择 `Subscribe`，在 URL 一栏粘贴并点击保存。

## 三、分流模式选择与防踩坑指南

小火箭主界面上方提供了几种“全局路由”工作模式，新手用户务必理解其差异：

| 路由模式 | 流量走向说明 | 适用场景 |
| :--- | :--- | :--- |
| **配置 (Config)** ⭐ 推荐 | 国内网站直连不耗流量，国外被墙网站自动走高速专线 | 日常 99% 的主力使用环境 |
| **代理 (Proxy)** | 所有网络请求（包括微信、百度、淘宝）全部强制走代理 | 仅在外服游戏或必须使用全局海外 IP 时 |
| **直连 (Direct)** | 相当于直接断开梯子，所有流量走本地运营商 | 排查本地网络故障时 |

```txt
日常最佳设定建议：
1. 全局路由模式：选择【配置】
2. 订阅自动更新：进入【设置】->【订阅】-> 勾选【打开时更新】与【自动更新】
3. 节点延迟测速：长按节点列表上方“连通性测试”，可一次性测出所有节点的真实晚高峰响应延迟
```

## 四、常见疑问解答 (FAQ)

### Q1：开启小火箭后微信发不出消息或高德地图定位漂移？
**原因**：你误选了“代理”模式，或者使用了不合规的全局规则。请将主界面的全局路由切换回**“配置”**模式即可。

### Q2：提示 VPN 权限连接失败？
首次连接时，iOS 系统会弹出“Shadowrocket 想要添加 VPN 配置”的系统对话框，点击“允许”并输入锁屏密码授予权限即可正常生效。
