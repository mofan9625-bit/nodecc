## 二、机场订阅链接导入方法（两种方式）

要让 Clash 正常工作，必须先将机场服务商提供的订阅链接导入客户端中。

### 方法 1：一键导入（最推荐，适合新手）

1. 在浏览器中登录你的机场用户后台（如 [云界线](/reviews/yunjiexian-review/) 或 [大佬云](/reviews/dalaoyun-review/)）；
2. 在首页仪表盘找到 **“便捷导入”** 或 **“一键订阅”** 区域；
3. 点击 **“一键导入 Clash / Clash Verge”** 按钮；
4. 浏览器会弹出系统提示：*“要打开 Clash 吗？”*，点击 **“打开”**；
5. 此时 Clash 会自动唤起，并在后台完成节点配置文件的下载与解析。当界面显示绿色勾选或配置卡片加载完成，即代表导入成功。

[图片占位：此处展示机场后台面板一键导入按钮及浏览器唤起客户端的交互截图]

### 方法 2：手动复制链接导入（备用方案）

若浏览器未能成功唤起客户端，可采用手动复制方式：
1. 在机场后台点击 **“复制订阅地址”**（通常为一串 HTTPS 开头的链接）；
2. 打开 Clash 客户端，在左侧导航栏点击 **`Profiles`（配置）**；
3. 在顶部输入框粘贴刚才复制的订阅 URL，随后点击右侧的 **`Download`（下载）** 按钮；
4. 等待几秒钟，直到出现刚刚导入的配置卡片，**鼠标单击该卡片选中使其高亮生效**。

## 三、节点选择与全局路由分流模式解析

配置导入成功后，即可开始科学上网。正确设置分流模式是保证日常使用流畅的关键。

### 1. 选择你需要的出海节点
点击左侧菜单栏的 **`Proxies`（代理）**：
- 顶部通常会有一个名为 `PROXY`、`节点选择` 或 `Auto` 的策略组；
- 点击展开后，你会看到香港（HK）、日本（JP）、新加坡（SG）、美国（US）等所有可用节点；
- **测速建议**：点击右上角类似 Wi-Fi 信号的小图标即可进行“批量连通性延迟测速”，优先选择延迟在 20ms~50ms 之间且显示为绿色毫秒数的低延迟专线节点。

### 2. 路由分流模式怎么选？
在 `Proxies` 页面最顶端，通常有四种运行模式，小白用户请牢记以下区别：

- **Rule（规则模式 - ⭐ 强烈推荐日常使用）**：
  - **工作机制**：Clash 内置的智能分流规则会自动识别目标网址。访问国内网站（百度、淘宝、微信、B站）走本地宽带直连，不耗费梯子流量且速度极快；只有访问 Google、YouTube、GitHub 等境外被封锁网站时才会自动走代理节点。
- **Global（全局模式）**：
  - **工作机制**：电脑的所有网络请求无论境内境外，全部强制走选中的海外节点。容易导致国内 App 打开变慢或无法加载，仅建议在外服特定游戏或调试特定 IP 时临时开启。
- **Direct（直连模式）**：
  - **工作机制**：完全绕过代理，所有流量直连公网，相当于暂时关闭梯子功能。

## 四、开启系统代理与常见故障排查（FAQ）

### 第一步：开启系统代理开关
设置好节点与分流模式后，最后一步是启动系统代理接管：
1. 点击左侧导航栏的 **`General`（常规）** 选项卡；
2. 找到 **`System Proxy`（系统代理）** 开关，将其切换为 **ON（开启）**；
3. 打开浏览器访问 `youtube.com` 或 `google.com`，能顺畅秒开即说明配置全部完成！

### 新手常见故障自查清单

#### Q1：开启 System Proxy 后依然打不开 Google 怎么办？
- **检查配置是否选中**：回到 `Profiles` 界面，确认你下载的订阅卡片是否为高亮被选中的激活状态；
- **检查节点是否超时**：进入 `Proxies` 界面点击测速，如果所有节点都显示 `Timeout`（超时），说明你的订阅链接已过期、流量耗尽，或者当前网络运营商阻断了该机场的入口公网 IP。

#### Q2：关闭电脑或退出客户端后，电脑所有网页都打不开了？
- **原因**：这是因为你在退出 Clash 前没有正常关闭系统代理，导致 Windows 系统网络设置残留了本机的代理端口指向；
- **解决方法**：重新打开 Clash，将 `System Proxy` 开关关闭后再正常退出；或者进入 Windows 系统【设置】->【网络和 Internet】->【代理】，手动将“使用代理服务器”开关关闭即可恢复。

#### Q3：玩外服游戏或某些终端命令行应用不走代理？
- **进阶技巧**：在 General 界面开启 **`TUN Mode`（虚拟网卡模式）**。TUN 模式会由驱动层接管电脑所有底层 UDP/TCP 流量，无需任何第三方应用设置即可实现真正的整机全局无缝代理。
