## 💻 技术架构特点 (Tech Stack)

- **核心框架**：Astro 5.x 静态站点生成 (SSG)，极速首屏加载与 100 分 Lighthouse 性能。
- **SEO 深度优化**：
  - 符合 Google / Bing 规范的 `BreadcrumbList` 面包屑与 `TechArticle` / `Review` 结构化数据 (JSON-LD)。
  - Clean URL 路径规范，杜绝内链 Canonical 冲突。
  - 自动化全量 `sitemap.xml` 生成与 IndexNow 毫秒级搜索引擎提交。
  - 友好支持现代 AI 搜索爬虫（PerplexityBot, GPTBot, ClaudeBot）。
- **样式与交互**：Tailwind CSS 暗黑模式智能适配，全站模糊搜索（Command Palette / ⌘K）。

## 💡 本地开发与构建指令

```bash
# 1. 安装项目依赖
npm install

# 2. 启动本地热重载开发服务器
npm run dev

# 3. 生产环境标准构建 (含 Sitemap 校验与 IndexNow 实时推送)
npm run build

# 4. 生成可直接离线双击预览的静态包
npm run build:offline
```
